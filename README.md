# Task Manager v3.0

一个基于Python的命令行任务管理应用，具备全面的任务操作功能和JSON持久化存储。

##  项目概述

Task Manager v3.0 是一个功能完整的任务管理系统，展示了现代软件架构的核心模式：菜单驱动调度 → 业务逻辑 → 持久化层。该项目采用分层架构设计，清晰的职责划分使代码易于维护和扩展。

---

##  功能特性

| 功能 | 说明 |
|------|------|
|  添加任务 | 支持输入任务名称和优先级（高/中/低） |
|  查看任务 | 显示所有任务，包含完成状态、优先级和名称 |
|  删除任务 | 根据编号删除指定任务 |
|  完成任务 | 标记任务为已完成 |
|  修改任务 | 编辑任务名称和优先级 |
|  搜索任务 | 按关键词搜索任务 |
|  数据持久化 | 自动保存到JSON格式文件 |

##  项目结构

Task_Manager_v3.0_AI_Annoation/
├── main.py              # 程序入口，CLI菜单分发器
├── task_manager.py      # 核心任务操作逻辑
├── storage.py           # JSON持久化操作
├── tasks.json          # 任务数据存储文件（自动生成）
└── README.md           # 项目文档

### 核心模块说明

#1# [main.py](main.py)
- **职责**: 命令行菜单分发
- **关键特性**:
  - 字典映射用户输入 (1-7) 到对应功能函数
  - 程序启动时加载任务，每次操作后自动保存
  - 实现主循环和退出逻辑

#2# [task_manager.py](task_manager.py)
- **职责**: 核心业务逻辑和UI交互
- **主要函数**:
  - `print_menu()` - 显示菜单
  - `task_add()` - 添加新任务
  - `task_check()` - 查看任务列表
  - `task_delete()` - 删除任务
  - `task_complete()` - 完成任务
  - `task_edit()` - 修改任务
  - `task_search()` - 搜索任务
  - `exit_tasks()` - 退出程序

#3# [storage.py](storage.py)
- **职责**: JSON数据个久化
- **主要函数**:
  - `load_tasks()` - 从任务.json读取任务列表
  - `save_tasks(tasks)` - 将任务列表保存到tasks.json

## 📊 数据模型

任务对象结构 (JSON):

```json
{
  "title": "任务描述",
  "done": false,
  "priority": "中"
}
```

**字段说明**:
- `title` (字符串): 任务名称/描述
- `done` (布尔值): 完成状态 (false=未完成, true=已完成)
- `priority` (字符串): 优先级等级
  - `"高"` - 高优先级
  - `"中"` - 中优先级（默认值）
  - `"低"` - 低优先级

##  安装和使用

### 前置要求
- Python 3.6+
- 无外部依赖

### 运行应用

python main.py

### 交互式操作流程

1. **选择功能**: 输入菜单对应的数字 (1-7)
2. **按提示输入**: 根据程序提示输入相关信息
3. **自动保存**: 每次操作完成后任务自动保存到 `tasks.json`
4. **退出程序**: 选择菜单选项 "7" 退出

### 使用示例

#### 添加任务
```
==== Task_Manager ====
1 添加任务
2 查看任务
3 删除任务
4 完成任务
5 修改任务
6 搜索任务
7 退出

请选择：1
请输入任务：完成项目报告
请输入优先级(高/中/低):高
```

#### 查看任务
```
请选择：2
==== 任务列表 ====
1. [ ] (高) 完成项目报告
2. [ ] (中) 学习Python
3. [✔] (低) 阅读文档
```

#### 搜索任务
```
请选择：6
请输入搜索关键词：Python
搜索结果：
1. [ ] (中) 学习Python
```

##  架构设计模式

### 1. 菜单驱动分发模式

menu_actions = {
    "1": task_add,
    "2": task_check,
    # ...
}

通过字典映射实现命令分发，易于添加新功能。

### 2. 输入验证模式
- 任务名称空值检查
- 任务重复检查
- 优先级验证（无效则默认为"中"）
- 任务编号边界检查

### 3. 数据持久化模式
- 每次操作后立即保存
- UTF-8编码保护中文字符
- JSON格式易于解析和扩展

### 4. UI显示规范
- 使用1-based索引匹配用户输入
- 清晰的任务状态符号（✔/空格）
- 统一的提示信息格式

##  扩展指南

### 添加新功能

1. **在 [task_manager.py](task_manager.py) 中新增函数**:
   ```python
   def task_new_feature(tasks):
       """新功能说明"""
       # 实现业务逻辑
       pass
   ```

2. **在 [main.py](main.py) 中注册函数**:
   ```python
   menu_actions = {
       "1": task_add,
       # ...
       "8": task_new_feature  # 新增
   }
   ```

3. **更新菜单显示**:
   在 `print_menu()` 函数中添加新选项。

### 扩展数据字段

修改任务对象结构，例如添加截止日期:
```python
task = {
    "title": title,
    "done": False,
    "priority": priority,
    "deadline": "2026-03-04"  # 新字段
}
```

##  技术细节

### 字符编码
- 文件编码: UTF-8
- JSON参数: `ensure_ascii=False` (保留中文字符)
- 输出格式: `indent=2` (美化JSON缩进)

### 控制流
- 函数返回 `True` 触发程序退出
- 函数返回 `None` 继续主循环
- 异常处理采用try-except模式

### 内存管理
- 任务列表直接在内存中修改
- 通过 `save_tasks()` 调用立即持久化
- 无需手动管理文件句柄
